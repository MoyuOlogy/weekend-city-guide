怎么用跨设备同步

云端房间创建房间后把 6 位房间码发给同学。页面每 6 秒自动同步、改动即上传；发布前会先拉取合并，不会用较少的数据抹掉别人的贡献。
分享链接把数据打包进网址，任何设备打开即导入，永久有效、不依赖第三方服务。
导入导出导出 JSON 留档；导入 JSON 支持选择文件或直接粘贴。

技术栈

形态原生 HTML + CSS + JavaScript，零依赖、零构建，GitHub Pages 静态托管
结构index.html 只留骨架；样式在 assets/css/（5 个），脚本在 assets/js/（21 个模块）
加载经典 <script defer>，不用 ES module —— module 在 file:// 下会被 CORS 挡掉，那样就不能直接双击打开页面了
数据浏览器 localStorage，v1 数据自动迁移
天气Open-Meteo（免费、无需 Key）
同步textdb.dev 公共存储（免注册）
节假日2026 年放假安排：国办发明电〔2025〕7号
视觉主色 #ff2442；24×24 单色矢量图标，不用 emoji 做图标；全站禁用蓝紫色相，有自动化断言守着
部署GitHub Pages 纯静态托管（不能跑服务端语言）；文件名大小写敏感，Windows 本地不敏感

已知限制

  • 房间基于公共服务 textdb.dev：房间码即钥匙，任何拿到它的人都能读写，请勿放敏感信息；重要内容请用分享链接或导出 JSON 留档。
  • 活动是示例数据（16 条内置），封面是 CSS 渐变 + emoji 生成的占位图，没有真实照片。
  • 距离为示例值，未接定位与真实通勤时间；无账号体系，昵称仅在本机登记。
  • 同步靠轮询（6 秒），不是 WebSocket 实时推送。
  • 节假日是硬编码的 2026 年安排（国办发明电〔2025〕7号）：跨年后需要更新，不会自动跟随。

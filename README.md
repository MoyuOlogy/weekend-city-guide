# 🧭 周末城市探索指南 · Weekend City Guide

一个面向大学生的周末城市探索指南原型：根据 **偏好 · 天气 · 预算 · 同行人数** 推荐本地活动，并支持 **组队出发、打卡记录、攻略分享**。

🔗 在线访问：**https://moyuology.github.io/weekend-city-guide/**

## ✨ 已实现功能（v1.0 原型）

| 模块 | 能力 |
| --- | --- |
| 🔍 探索推荐 | 城市切换（8 城）、周六/周日、人均预算滑块、同行人数、可支配时长、活动类型多选、额外偏好（近 / 省 / 出片 / 新手友好）；实时重排推荐并给出「匹配度 + 推荐理由 + 风险提示」 |
| 🌤 天气联动 | 通过 Open-Meteo 免费 API 拉取真实天气预报（无需 Key），下雨自动压低户外活动权重、优先室内；网络异常自动降级为示例天气 |
| 👥 组队出发 | 创建队伍（昵称 / 活动 / 集合时间 / 招募人数 / 人均预算）、加入退出、进度条、一键复制邀请文案、发起人可解散 |
| 📍 打卡记录 | 记录地点、日期、花费、时长、心情、感想；自动统计次数 / 总时长 / 总花费；时间线展示与删除 |
| 📝 攻略分享 | 发布标题 + 正文 + 标签，卡片流展示，点赞互动 |

所有数据保存在浏览器 `localStorage`，无需登录、无后端。

## 🛠 技术栈

单文件 `index.html`：原生 HTML + CSS + JavaScript，零依赖、零构建，直接由 GitHub Pages 静态托管。推荐引擎采用**可解释加权评分**（类型 / 天气 / 预算 / 人数 / 时长 / 距离 / 加分偏好），每条推荐都会说明为什么推荐。

## 🚀 本地预览

```bash
# 直接双击 index.html 即可；或起个静态服务

# 打开 http://localhost:8080
```
